# Buildto — Construction Materials Platform

This project is adapted from the Kraveo marketplace into **Buildto**, a multi-vendor construction materials delivery platform. The Customer Flutter App has been rebranded with full construction materials cataloging (cement, steel & TMT bars, bricks & blocks, sand & aggregates, plumbing, electricals, and paints).

| Directory | Purpose |
|---|---|
| `apps/customer_app/` | Flutter customer app (`in.buildto.customer`) |
| `apps/vendor_app/` | Flutter vendor app |
| `apps/driver_app/` | Flutter delivery partner app |
| `packages/kraveo_ui/` | Shared Flutter design system and brand configuration |
| `branding/` | Buildto identity, shared logo, palette and Android application IDs |
| `backend/` | Express/TypeScript, Prisma/PostgreSQL, payments and dispatch |
| `web/super_admin/` | Operations website |
| `demo/preview/` | Interactive 16-screen browser demonstration prototype (`index.html`) |
| `Docs/` | Documentation and architecture references |
